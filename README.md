## How to upload to GitHub

1. Create a new GitHub repository, for example: `zuzu-auto-glass`.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save.
6. GitHub will give you a live website URL.

## Custom domain

If using `zuzuautoglass.ca`, update the `CNAME` file with your domain and configure DNS at your domain provider.
